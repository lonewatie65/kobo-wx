# ESP32-S3

## Role

The ESP32-S3 is the controller for Kobo-WX. It will read the attached environmental sensors and initially send measurements to a computer over USB serial.

## Initial use

1. Install MicroPython firmware.
2. Connect the sensor on a breadboard.
3. Read temperature and relative humidity.
4. Output simple readings over USB serial.
5. Later output structured JSON and add local Wi-Fi networking.

## Design preference

The first build should remain simple, local, understandable, and easy to troubleshoot. Cloud services are not required.

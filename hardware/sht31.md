# SHT31

## Role

The SHT31 is the initial Kobo-WX environmental sensor.

## Measurements

- Temperature
- Relative humidity

From these measurements, software can also calculate values such as dew point.

## Interface

The sensor communicates with the ESP32-S3 over I2C.

## First milestone

Confirm that the ESP32-S3 can detect the SHT31 and repeatedly read stable temperature and humidity values.

## Status

Hardware acquired / testing pending.

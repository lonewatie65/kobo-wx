# Build Logs

This folder is the chronological workshop notebook for Kobo-WX.

Build logs should record what was actually attempted: wiring changes, commands, code tests, readings, failures, fixes, and observations.

A useful filename format is:

`YYYY-MM-DD-short-description.md`

Example:

`2026-08-16-first-sht31-test.md`

Documentation describes how the project should work. Build logs preserve what actually happened.
